mend is one command-line patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edit commands to a tree of files. It matches lines in three tiers (exact, trailing-whitespace-insensitive, leading-and-trailing-whitespace-insensitive with re-indentation), supports a strict mode, a dry-run check mode, and writes nothing at all when any edit fails.

## Run it

```sh
node main.ts [PATCH]
```
